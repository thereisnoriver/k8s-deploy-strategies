# Twelve-Week Kubernetes Learning Roadmap

**Status: learning plan, not a record of completed tasks.**

**Adapted from:** [Three-month Kubernetes study roadmap (/34)](https://tyge-ottesen-brahe.tistory.com/34) (May 2025). The original post presented unchecked learning milestones. They remain **prospective** here.

| Weeks | Planned focus | Suggested verifiable artifact |
| --- | --- | --- |
| 1–4 | Containers, Pods, Deployments, Services, and fundamental kubectl operations | Versioned manifests, cluster diagram, sanitized command logs |
| 5–8 | Ingress, persistent storage, ConfigMaps/Secrets, Helm, and practical app deployment | Small reproducible example with validation notes |
| 9–12 | Cluster operations, CI/CD, observability, updates, and resilience | Automated pipeline and failure-test report with timings |

## How to document real completion

For each exercise, keep:
1. An explicit environment: OS, Kubernetes distribution and version, and container runtime.
2. The expected behavior and test command.
3. Observable output, logs, screenshots, or a test report with dates.
4. A short analysis of what failed and what changed.
5. Links to commits that contain the implementation.

Do not mark a phase as complete based solely on having written an explanatory article. The [original 14-day plan](ORIGINAL_STUDY_PLAN.md) is also preserved separately as historical planning material.
